# TestCraft

A tool that turns plain English user stories into software test cases.

You type in a user story, it generates the test cases - happy path, edge cases, what happens when things go wrong - and explains why each one was created. You can export everything as a PDF or Excel file.

## Running it locally

You need Python 3.10+ and Node.js 18+.

```bash
# backend
cd backend
./run.bat

# frontend (new terminal)
cd frontend
npm install
npm start
```

Open `http://localhost:3000` in your browser.
